# 設計研究：landing page 的資訊呈現手法

這份文件記錄改版時參考的網站、觀察到的手法，以及它們在本站的用法。
目的是讓之後的設計決策有依據可查，而不是憑印象重來。

研究日期：2026-09-22。量化數據是在瀏覽器裡用 `getComputedStyle` 實際量測頁面得到的。

## 起因

前一版為了追求圓潤感，把幾乎所有內容都放進圓角卡片。卡片疊卡片的結果，正是常見的生成式設計套路：
內容被切成一模一樣的圓角方塊，每塊有相同的陰影與圓角，資訊之間沒有主次。

## 量化觀察：頂尖網站其實很少用卡片

| 網站 | 大區塊數 | 含卡片的區塊 | 主要替代手法 |
|---|---|---|---|
| Stripe | 13 | 4 | 大字標題、大量插圖、顯性網格線 |
| Anthropic | 7 | 0 | 細線索引清單、分割式開場、媒體面板 |

卡片只出現在「需要並列比較」的少數情境，例如 Stripe 的產品選擇。

## 術語表

每一條都附上來源網站與它解決的問題。

### 版面結構

**Split Hero（分割式開場）**
左邊大標題、右邊一段說明並排，而不是上下堆疊。來源：Anthropic。
解決：首屏資訊密度低、視線只能往下走。

**Visible Grid（顯性網格）**
用 1px 細線畫出版面的欄與列，結構由線撐起，不需要卡片的邊框與陰影。來源：Stripe（內容區左右兩條直線、logo 列上下橫線）。
解決：拿掉卡片後版面鬆散、沒有邊界。

**Hairline Index（細線索引清單）**
一列一資訊，列與列之間只有 1px 細線，欄位對齊。來源：Anthropic 的 Latest releases（12 條細線、0 張卡片）。
解決：清單型內容（電子報、文章）被切成卡片後難以掃讀。

**Sticky Storytelling（固定式捲動敘事）**
一側固定不動（圖片或大數字），另一側文字捲過時，固定側跟著切換。來源：21st.dev Scroll 01、Apple 產品頁。
解決：有先後順序的內容（階段、流程）用並排卡片呈現時，看不出順序。

**Media Panel（媒體面板）**
全頁唯一的大圓角面板，留給最重要的一張圖或一個行動呼籲。來源：Anthropic。
解決：面板用太多就失去重點。只用一次，它才是焦點。

### 文字

**Tonal Headline（明度分層標題）**
一段長標題裡，前半句用深色、後半句用淺色，用明度分出主次。來源：Stripe。
注意：這和「只把一個詞塗成別的顏色」不同，後者是生成式設計的典型特徵。

**Linked Headline（標題即導覽）**
標題裡的關鍵詞本身就是連結，加底線標示。來源：Anthropic。
解決：首屏的按鈕太多、太像廣告。

**Type Pairing Contrast（字體對比配對）**
標題與說明使用明顯不同的字體類型（例如襯線與無襯線）。來源：Anthropic。

**Statement Section（宣言式段落）**
一整個區塊只放一句大字主張，不配任何元件。
解決：重要的論點被塞進卡片裡，跟其他資訊一樣大。

### 互動

**Hover Reveal List（懸停顯圖清單）**
一列列純文字，滑到哪一列，游標旁浮出那一項的圖。來源：21st.dev Hover Image List、Services with Animated Hover Modal。
解決：每一項都有圖時，全部攤開會讓頁面變成圖片牆。

**Live Ticker（即時計數）**
統計數字從 0 滾動到實際值，或持續跳動。來源：Stripe 的「Global GDP running on Stripe」、21st.dev Number Ticker。
解決：靜態數字沒有存在感。

**Inner Highlight（內側高光）**
元素頂部一道 1px 半透明白色內陰影，讓平面有厚度。來源：Raycast。

### 信任

**Logo Wall / Proof Strip（信任列）**
一排合作對象或客戶的標誌。來源：Stripe。
本站版本：評測平台的裝置與廠商。

## 本站各區塊的對應

| 區塊 | 上一版 | 這一版改用 | 理由 |
|---|---|---|---|
| 開場 | 置中大標＋兩顆按鈕 | Split Hero、Tonal Headline、Live Ticker | 首屏同時交代主張、說明與規模 |
| 評測裝置 | 膠囊跑馬燈 | Proof Strip 搭配 Visible Grid | 裝置本身就是信任來源 |
| 超人與鋼鐵人 | Bento 裡的一張卡片 | Statement Section＋對照欄 | 這是聯盟的核心論點，不該跟數字卡一樣大 |
| 實測數據 | 兩張數字卡 | Visible Grid 數字帶＋Live Ticker | 數字要一眼橫向比較 |
| 三個階段 | 三張並排卡片 | Sticky Storytelling | 階段有先後，捲動才看得出順序 |
| Edge Landing 七項 | 七張卡片網格 | Hover Reveal List | 七項都有實機照，攤開會變成圖片牆 |
| 電子報 | 三張卡片 | Hairline Index | 清單型內容，要能掃讀日期與標題 |
| 結尾行動呼籲 | 圓角極光面板 | 保留，作為全頁唯一的 Media Panel | 只用一次才是焦點 |

### 內頁

| 頁面 | 區塊 | 改用 |
|---|---|---|
| 關於聯盟 | 聯盟為什麼存在 | 分割排版：左邊一句明度分層的大字，右邊說明 |
| 關於聯盟 | 基本資料 | Visible Grid 的定義列表 |
| 關於聯盟 | 累積數字 | Visible Grid 數字帶＋Live Ticker |
| 關於聯盟 | 核心論點 | Statement Section |
| 關於聯盟、成為會員 | 服務方向 | Hairline Index |
| 成為會員 | 入會三步驟 | Visible Grid 流程列，描邊大數字標順序（真的有先後才編號） |
| 聯絡我們 | 窗口與主辦單位 | Visible Grid 兩欄 |
| 聯絡我們 | 相關連結 | Hairline Index |
| 電子報 | 各期列表 | 年份為固定大標＋Hairline Index |
| 各期電子報 | 文章清單 | Hairline Index，上下期導覽改成三格 Visible Grid |
| 使用條款 | 章節 | 細線分隔的純文字，目錄改為左側一條線 |
| 核心服務 | 示範機型與截圖 | 圓角圖片框＋下方說明，不包成卡片 |

改版後以同一套判準量測每一頁：內容卡片全站只剩服務頁的兩張評測圖表，其餘頁面為 0。
判準是「有圓角、且有陰影或邊框、寬度大於 180px、高度大於 120px 的元素」。

## 卡片還該用在哪裡

只在「需要並列比較、每一項結構相同」時使用，例如服務頁的評測圖表。
其他情況先考慮上面的手法。
